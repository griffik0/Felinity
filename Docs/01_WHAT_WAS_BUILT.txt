--------------------------------------------------------------------------------
PROMPT 1 — PROJECT FOUNDATION
--------------------------------------------------------------------------------
• Folder structure under Assets/ (Art, Scripts, Prefabs, Scenes, Audio, Tilemaps)
• Packages: 2D Animation, 2D Tilemap Editor, Cinemachine (installed/verified)
• Scene: Assets/Scenes/MainWorld.unity
  - Player: Rigidbody2D (gravity 0), CircleCollider2D, white SpriteRenderer
  - Cinemachine Virtual Camera: orthographic, follows Player, damped
  - Grid → Ground tilemap + Collision tilemap (TilemapCollider2D on Collision)
• Scripts/Player/PlayerController.cs
  - WASD / arrows, 8-direction, normalized diagonals
  - Rigidbody2D.MovePosition in FixedUpdate
  - public moveSpeed (default 4)
  - IsMoving + OnInteract() (later wired to interaction system)

PROMPT 2 — DAY / NIGHT + CURFEW
--------------------------------------------------------------------------------
• Scripts/Systems/DayNightCycle.cs (singleton)
  - CurrentHour 0–24, minutesPerRealSecond, OnHourChanged
  - IsDaytime 6:00–19:00, IsNight 19:00–6:00
  - Lerps Global Light 2D color/intensity (dawn/noon/dusk/night)
• Scripts/Systems/GameClockUI.cs — top-right "H:MM AM/PM"
• Scripts/Player/HomeCurfew.cs — night warning + midnight soft teleport home
• CatBed uses Assets/Art/Sprites/Beds/tier_1.png (tag Home, HomeCurfew target)
• GameUI Canvas: ClockText, CurfewWarningText, FadePanel

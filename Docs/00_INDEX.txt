--------------------------------------------------------------------------------
QUICK START — MOST COMMON EDITS
--------------------------------------------------------------------------------
• How to play the current build     → Docs/08_HOW_TO_PLAY.txt
• Player speed / interact range     → Player object → PlayerController
• Day length / start time           → DayNightCycle object
• Curfew radius / midnight hour     → Player → HomeCurfew
• Scratch reward                    → ScratchPost → coinsPerScratch
• Forage drops / respawn time       → ForagePatch → possibleDrops / respawnSeconds
• Active quests                     → QuestManager → activeQuests list
• New quest asset                   → Project: right-click → Create → Quests → New Quest
• New item asset                    → Project: right-click → Create → Items → New Item

NOTE: After each new feature prompt, 08_HOW_TO_PLAY.txt should be updated so
controls, UI, and "what you can do" always match the live game.

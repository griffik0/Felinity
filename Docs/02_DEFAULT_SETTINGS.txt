02 — DEFAULT SETTINGS (HOW TO TUNE WHAT EXISTS)
================================================================================
Change these in the Unity Inspector on the listed object/component.
Values below are the current defaults from the initial setup.

--------------------------------------------------------------------------------
PLAYER MOVEMENT & INTERACTION
--------------------------------------------------------------------------------

Component:  PlayerController

  moveSpeed            = 4
  interactionRadius    = 1.25   (also sets InteractionRange CircleCollider2D)

Component:  PlayerFacing
  idleSouth..idleSouthWest = Assets/Art/Sprites/Cat/Idle/cat_idle_*.png
  walkSouth..walkSouthWest = Assets/Art/Animations/Cat/walk_*/frame_0..7 (8 each)
  frameDuration            = 0.1   (2x original 0.2s export delay)
  facing (default)         = South
  Import: Sprite, PPU 48, Point filter

  isTrigger            = true

            E or Left Click interact

--------------------------------------------------------------------------------
DAY / NIGHT CYCLE
--------------------------------------------------------------------------------
Object:     DayNightCycle
Component:  DayNightCycle

  minutesPerRealSecond = 1      → 1 real second = 1 in-game minute
                                → full 24h ≈ 24 real minutes
  startHour            = 8      → game starts at 8:00 AM
  globalLight          = Global Light 2D (assigned)

  IsDaytime            = 6:00 inclusive → 19:00 exclusive
  IsNight              = otherwise

  Light keyframes (hardcoded in script — edit DayNightCycle.cs to change):
    Hour 0 / 24  dim blue     intensity 0.35
    Hour 6       orange dawn  intensity 0.75
    Hour 12      warm noon    intensity 1.25
    Hour 19      orange dusk  intensity 0.65

Tips for testing:
  • Set minutesPerRealSecond to 10–60 to speed through a day
  • Set startHour to 18.5 to begin near dusk / curfew

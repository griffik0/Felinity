================================================================================
HOW TO PLAY — FELINITY
================================================================================
Last updated: Character Creation (coat + name)

Open the project and press Play (Editor is set to boot TitleScreen first).
In a built player, Build Settings order is:
  0 = TitleScreen → 1 = CharacterCreation → 2 = MainWorld

--------------------------------------------------------------------------------
GOAL (FOR NOW)
--------------------------------------------------------------------------------
Explore a small top-down map as a cat. Scratch posts for CatCoins, forage for
items, complete quests, and get home before midnight when night falls.

--------------------------------------------------------------------------------
TITLE SCREEN
--------------------------------------------------------------------------------
Title text: "Felinity"
  Change the name in: Scripts/Systems/GameFlow.cs → public const string GameTitle

Buttons:
  Start Game   → loads CharacterCreation
  Quit         → stops Play Mode in Editor, or Application.Quit() in a build

--------------------------------------------------------------------------------
CHARACTER CREATION
--------------------------------------------------------------------------------
Live preview of your cat (idle poses cycle; palette-swap coats).

  Coat            ◀ / ▶ arrows cycle Orange Tabby → Black → Grey → Cream
                  Center swatch shows the current coat color + name.
  Name            Type a name (max 16). Placeholder is "Whiskers".
  Confirm         Enabled only when the name field is non-empty.
                  Loads MainWorld with your coat + name on PlayerProfile.

Choices live on PlayerProfile (DontDestroyOnLoad). Console on MainWorld start:
  Welcome, <catName>!

If you Play MainWorld directly (skipping Character Creation), defaults are
Orange Tabby / "Whiskers".

--------------------------------------------------------------------------------
CONTROLS (IN MAINWORLD)
--------------------------------------------------------------------------------
Move                 WASD  or  Arrow keys  (8 directions; diagonals are normalized)
Interact             E  or  Left mouse click
Pause / Resume       Escape
Coat debug           1 = Orange Tabby, 2 = Black, 3 = Grey, 4 = Cream

When something is in range, a prompt appears above you:

  [E] Scratch
  [E] Forage

Your cat faces the direction you last moved (N/NE/E/SE/S/SW/W/NW).
While moving, a walk loop plays for that direction (8 frames, 0.1s each — 2x the export delay).
When you stop, the matching idle pose is shown.

--------------------------------------------------------------------------------
PAUSE MENU
--------------------------------------------------------------------------------
Press Escape to pause (Time.timeScale = 0 — world clock/movement freeze).
Press Escape again, or click Resume, to continue.

  Resume          → unpause
  Quit to Title   → returns to TitleScreen (resets timeScale)
  Quit Game       → quit / stop Play Mode

--------------------------------------------------------------------------------
ON-SCREEN UI (MAINWORLD)
--------------------------------------------------------------------------------
Top-left
  CatCoins: X              Your currency
  Quests:                  Active quest list (e.g. First Scratch: 0/3)

Top-right
  Clock                    In-game time as H:MM AM/PM

Top-center (night only, if far from home)
  "Head home before midnight!"   (pulses / blinks)

Bottom-left
  Inventory:               Items you are holding (e.g. Catnip x2)

Above player (when near an interactable)
  [E] <action name>

--------------------------------------------------------------------------------
WHAT YOU CAN DO
--------------------------------------------------------------------------------
1) MOVE AROUND
   You are the cat character with idle + walk art.
   Camera follows smoothly. Facing and walk loops update with direction.

2) SCRATCH THE SCRATCHING POST ("ScratchPost")
   - Walk up to the scratching post prop until you see [E] Scratch
   - Press E / click
   - Gain +2 CatCoins each scratch
   - Progresses the "First Scratch" quest (need 3 scratches)

3) FORAGE THE BUSH ("ForagePatch")
   - Walk up to the foraging bush until you see [E] Forage
   - Press E / click
   - Receive one random item: Catnip, Wild Berry, or Feather
   - Bush disappears and respawns after 30 seconds
   - Inventory panel updates live

4) WATCH THE DAY / NIGHT CYCLE
   - Time starts around 8:00 AM and advances (default: 1 real second = 1 game minute)
   - Lighting shifts: warm midday → orange dusk/dawn → dim blue night
   - Daytime is roughly 6:00 AM – 7:00 PM; night is after that
   - Clock freezes while paused (uses Time.deltaTime)

5) RESPECT CURFEW AT NIGHT
   - Home is the CatBed (tier 1 bed sprite) tagged Home
   - At night, if you stray farther than ~3 units from CatBed, the warning appears
   - At midnight (0:00), if you are still too far, the screen fades to black,
     you are returned to CatBed ("you dozed off"), then the fade clears

6) COMPLETE QUESTS
   - Default active quest: First Scratch — scratch the post 3 times
   - On completion: quest log shows (Done), you gain +10 CatCoins,
     console logs a completion message

--------------------------------------------------------------------------------
TIPS FOR TESTING SYSTEMS QUICKLY
--------------------------------------------------------------------------------
• Speed up the day: select DayNightCycle → raise minutesPerRealSecond (e.g. 30–60)
• Start near night: DayNightCycle → startHour ≈ 18.5
• Forage again sooner: ForagePatch → lower respawnSeconds
• Speed up / slow walk anim: Player → PlayerFacing → frameDuration
• See all defaults: Docs/02_DEFAULT_SETTINGS.txt
